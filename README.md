# Домашняя работа №2
# Реализовать программу “связный список”. Программа должна содержать в себе следующий функционал:
1)	Программа должна принимать на вход параметры -t, -c, -e. Параметр -t отвечает за тип связного списка: 1 это - однонаправленный связный список, 2 это – двунаправленный связный список, 3 это – однонаправленный кольцевой связный список, 4 это – двунаправленный кольцевой связный список. Параметр -c отвечает за количество элементов из которых должен быть сформирован связный список, а параметр -e описывать сами элементы связного списка через запятую. В случае если количество переданных значений связного списка отличается от значения в параметре -c, то программа должна завершать выполнение с ошибкой. В случае если программа получает на вход любые другие параметры, не входящие в перечень описанных, то программа должна завершаться с ошибкой. 
2)	Программа должна содержать меню выбора действия. Меню должно обновляться после завершения выбранного действия и запрашивать действие заново. Меню должно работать до ввод пользователем символа завершения программы. За символ завершения программы рекомендуется принять 0.
3)	Программа должна содержать в себе следующий функционал: добавить элемент в связный список, вывести связный список, найти элемент в связном списке, удалить элемент из связного списка, удалить связный список, записать связный список в файл, считать связный список из файла. При работе с файлами должна считываться и записываться информация о типе связного списка: > – однонаправленный связный список, <> – двунаправленный связный список, >0 – однонаправленный кольцевой связный список, <>0 – двунаправленный кольцевой связный список. При попытке считать связный список из файла при наличии связного списка в программе должна выводиться ошибка. Функция поиска должна возвращать все позиции искомого элемента. Функция удаления должна иметь функционал удаления первого вхождения элемента и удаления всех вхождений элемента в список.
